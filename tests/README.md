# Регрессионные тесты плагина 1.16

Из корня ElvUI_DmgAtNameplates:

```bash
python -m pip install lupa
python -m unittest discover -s tests -p 'test_*.py'
```

Команда запускает весь набор, а не только `test_runtime.py`. Используется Lua 5.1; клиент и соседний клон ElvUI для самостоятельных тестов не нужны.

## Автоматические сценарии

- Настоящий путь `OnEvent → FilterEvent → обработчик → DisplayText → анимация/пул`, а не только подмена обработчиков.
- Критические и обычные автоатаки, уклонение/парирование/промах игрока, питомца и стража; входящие события по игроку. Формат SWING разбирается отдельно от SPELL/RANGE; события заклинаний и лечения сохранены.
- Персональная фильтрация и переключатели направлений: посторонний бой не появляется, в том числе с устаревшим `showFromAnotherPlayer`.
- Шрифт промахов, его восстановление после анимации, прозрачность категорий событий и иконок, смена профиля и повторное использование FontString.
- Настоящий поставляемый профиль, версия 1.16 и неизменный X-Sirus-Update.
- GUID-индекс: 1000 обращений к известному GUID без обходов; 1000 повторных обращений к отсутствующему GUID — один обход внутри окна кеша. Счётчик устанавливается **до загрузки Core**, захватывающего локальную ссылку на `pairs`; отдельный контрольный тест подтверждает, что счётчик действительно видит обход.
- Кеш промахов ограничен 128 записями и 0,1 секунды; тестируются истечение, появление/скрытие и повторное использование рамки, старый PlateGUID, отключение/включение и восстановление без хука.
- Строгая модель API без универсальных заглушек Set*/Get*: неизвестный метод вызывает ошибку. Отдельно проверяются шрифт до SetText/SetTextHeight, все четыре траектории анимации, затухание, очистка и один GetTime на кадр анимации.

В соседнем ElvUI-for-Sirus 9.09.08 запустить такую же команду discovery для общих интеграционных сценариев. Это отдельный набор, он не заменяет самостоятельные тесты плагина.

## Ручной чек-лист Sirus

- [ ] Игрок: обычная/критическая автоатака; удар заклинанием/периодический урон; промах, уклонение и парирование отображаются различимо.
- [ ] Питомец и страж: критические автоатаки и промахи отображаются; чужие питомцы/игроки не создают текст над посторонними целями.
- [ ] Входящий урон/лечение и собственное лечение отображаются только при включённом соответствующем направлении.
- [ ] Разные шрифты категорий: промах использует свой шрифт и сохраняет его после увеличения/уменьшения текста.
- [ ] Для промаха, рассеивания и прерывания установить разную прозрачность; проверить текст и иконку на протяжении всей анимации и после смены профиля.
- [ ] Многократные события по отсутствующей рамке, её последующее появление, скрытие и переработка не оставляют цифры старой цели. Текущая цель без видимого индикатора продолжает использовать резервную область.
- [ ] Проверить verticalUp/verticalDown/fountain/rainfall, отключённые анимации, отключение и повторное включение плагина.

Заглушки не воспроизводят рендеринг, защищённое исполнение/taint и все тайминги клиента. Ускорение алгоритма не является измеренным приростом FPS. Перед слиянием обязательна проверка в игре с ElvUI 9.09.08.
